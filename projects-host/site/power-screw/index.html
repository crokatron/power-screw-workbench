3D root diameter & assumptions

Solid right-hand trapezoidal thread. Crest width = pitch/4; root estimate and crest width are visual assumptions, not a manufacturing specification. Root controls affect the 3D model only. Torque uses mean diameter.

Friction estimate & supplier override

Material estimates describe sliding friction, not verified breakaway friction. The displayed bands are assumed sensitivity ranges, not guaranteed material limits. Manufacturing process alone does not establish friction, so no automatic friction reduction is applied for rolling or grinding. Enter supplier or measured data when available.

Reference anchors: Nook Acme data quotes 0.125 for its bronze nuts with Nook lubricant and 0.10 for lubricated plastic nuts. Applying those values to generic bronze/plastic pairs is a preliminary proxy. Dry estimates and all sensitivity bands are tool assumptions. igus friction guidance distinguishes static and sliding friction and the effect of operating conditions.

Include friction from a collar or thrust bearing using the mean-diameter model.

Collar friction adds to raising torque and reduces available back-drive torque.

Equations, assumptions & sign convention

Positive back-drive torque is available from the load in the lowering direction. A negative value means external lowering torque is needed. Neutral uses a numerical tolerance of 10⁻⁸ × max(1, Fdₘ/2, Tc) N·m, not a practical safety margin.

L = np; tan θ = L/(πdₘ); μe = μ/cos(α); α = included angle/2
T↑ = (Fdₘ/2)(tan θ + μe)/(1 − μe tan θ) + Tc
Tback = (Fdₘ/2)(tan θ − μe)/(1 + μe tan θ) − Tc
Tc = Fμc dc/2; Tideal = FL/(2π); η = Tideal/T↑

Torque equations use metres. Geometry is shown in millimetres. For estimated diameter in helix mode, the simultaneous solution is p = πd tan θ / (n + π tan θ/2). Critical pitch is thread-only: πdₘμe/n (manual) or πμe d/(n + πμe/2) (estimated).

This implements the handover’s conventional μ sec α friction approximation. It assumes quasi-static loading, constant friction, rigid geometry, uniform contact and mean-radius collar friction. It excludes inertia, lubricant shear, temperature, tolerances, deformation, seal and drivetrain drag. The collar input is a friction approximation, not a bearing catalogue loss model.

30° is the default trapezoidal included angle; enter the actual drawing angle for other thread forms. Use a specified pitch diameter for final torque work. Strength, root diameter, buckling, nut engagement, motor sizing and dynamic checks are not included in this Phase 1 build.
